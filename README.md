## Regras do repositório

| # | Regra |
|---|---|
| 1 | Um app por pasta, com nome curto, minúsculo e com hífen (ex.: `agenda-pedidos`). |
| 2 | Cada pasta tem seu próprio `index.html` e um `README.md` explicando o app. |
| 3 | Repositório PÚBLICO: nunca subir senhas, planilhas reais ou dados de pessoas, clientes ou da empresa. |
| 4 | Ao criar um app novo, adicionar uma linha na tabela de Apps. |
